# Ideas and suggestions for Researchdata.se

Help us improve Researchdata.se by sharing ideas, feature requests, metadata recommendations, usability feedback, and other suggestions.  

Suggestions can be submitted in either Swedish or English. 

## Browse or add suggestions

[🗃️ View all suggestions](https://github.com/researchdata-se/suggestions/discussions)

You are welcome to:
- Suggest new features and functionality.
- Suggest improvements to the functionality of Researchdata.se: the catalogue, search function, the data management pages.
- Suggest new content, such as guides, documentation, or other information related to research data and research data management.
- Discuss metadata recommendations and harvesting.
- Report on usability issues.
- Share ideas for workflows, integrations, and interoperability.
- Discuss other ways to improve the user experience. 

## If you don’t want to create a GitHub account 

Send your suggestions to the Researchdata.se team at researchdata@snd.se, and we will post it to the discussion board on your behalf.

## Idéer och förslag för Researchdata.se 

Hjälp oss förbättra Researchdata.se genom att dela med dig av idéer, funktionsönskemål, metadatarekommendationer, användarfeedback eller andra förslag. 

Du kan lämna förslag på svenska eller engelska. 

### Bläddra bland eller lägg till förslag 
[🗃️ Se alla förslag](https://github.com/researchdata-se/suggestions/discussions)  

Du får gärna: 
- Föreslå nya funktioner.
- Föreslå förbättringar av Researchdata.se: katalogen, sökfunktionen, datahanteringssidorna.
- Föreslå nytt innehåll, som guider och stöd, dokumentation eller annan information om forskningsdata och forskningsdatahantering.
- Diskutera metadatarekommendationer och skördning.
- Rapportera användarproblem.
- Dela med dig av idéer för arbetsflöden, integrationer och interoperabilitet.
- Diskutera andra sätt att förbättra användarupplevelsen.

### Om du inte vill skapa ett GitHub-konto 

Skicka dina förslag till Researchdata.se-teamet på researchdata@snd.se, så lägger vi in dem i diskussionsforumet för dig.
